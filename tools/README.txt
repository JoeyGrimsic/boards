Optional: if you'd rather not install yt-dlp / ffmpeg system-wide, drop
yt-dlp.exe and ffmpeg.exe in this folder and doodleboard will use them.

  yt-dlp.exe  ->  https://github.com/yt-dlp/yt-dlp/releases
  ffmpeg.exe  ->  https://www.gyan.dev/ffmpeg/builds/  (the "essentials" build, bin/ffmpeg.exe)
